# Yori Dict SQLite Data 2026-06-01

First public SQLite data release for Yori Dict.

## What's Included

- JMdict-simplified `3.6.2+20260601171836`
- 217,294 JMdict entries
- 675,094 senses
- 958,744 gloss rows
- 184,738 reviewed AI-assisted `zh-tw` gloss rows
- API-compatible SQLite schema used by the hosted Yori Dict API

## Assets

- `yori-dict-2026-06-01.sqlite.gz`
- `yori-dict-2026-06-01.sqlite.gz.sha256`
- `yori-dict-2026-06-01.json`

## Download And Verify

```sh
curl -LO https://github.com/anilahsu/yori-dict/releases/download/data-2026-06-01/yori-dict-2026-06-01.sqlite.gz
curl -LO https://github.com/anilahsu/yori-dict/releases/download/data-2026-06-01/yori-dict-2026-06-01.sqlite.gz.sha256
shasum -a 256 -c yori-dict-2026-06-01.sqlite.gz.sha256
gunzip yori-dict-2026-06-01.sqlite.gz
```

## Hosted API

- API root: https://yori-dict-production.up.railway.app
- API docs: https://yori-dict-production.up.railway.app/doc
- OpenAPI: https://yori-dict-production.up.railway.app/openapi.yaml

## Current Limitations

- `zh-tw` AI-assisted glosses are partial coverage, focused on reviewed common senses.
- `zh-cn` and `ko` are API language targets, but this release does not yet include committed reviewed gloss sources for them.
- Lookup returns only glosses for the requested language. It does not fall back to English.
