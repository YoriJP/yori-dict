# Product

## Register

product

## Users

Solo curator (the project owner) doing operational work on a multilingual Japanese dictionary: approving AI-generated translations, building and promoting releases, inspecting individual entries, creating new words. Technical, comfortable with dense interfaces, values scanning and acting quickly over being guided through steps. Sessions are focused and varied; the dominant task changes day to day.

## Product Purpose

Admin console for curating a multilingual Japanese dictionary. The curator uses it to manage AI translation review queues, build and ship immutable releases, inspect and edit entries, and add new words. Success is a curator who can context-switch between these tasks without friction, getting in and out efficiently.

## Brand Personality

**Editorial. Technical. Contemporary.**

The interface carries the typographic sophistication and information hierarchy of quality editorial design, but applied with the interaction sensibility of a modern tech tool. It is not retro or nostalgic; it is what happens when editorial care meets engineering precision. Typography does most of the work. The interface is dense where density serves the task, spacious where focus matters. It feels authored, not generated.

## Anti-references

- AI/dark-mode tech aesthetic (cyan-on-dark, neon accents, purple gradients, glassmorphism, glow effects)
- Overly decorative Japanese theming (kanji watermarks, ornamental borders, shrine-gate motifs, cherry blossom backgrounds)
- Wordy, hand-holding interfaces (long help text under every field, intro paragraphs that restate the heading)
- Generic "AI startup" or "developer tool" styling

## Design Principles

1. **Typography is the interface.** Hierarchy comes from weight, size, and spacing. If the type is well-set, you don't need a box around it.

2. **Editorial precision, tech speed.** Every screen should read like a well-edited page and respond like a fast tool. No decoration that slows the eye; no austerity that strips away character.

3. **Density follows task.** Review queues and entry inspectors are information-dense. Login and single-entry views are spacious. Don't pad uniformly.

4. **One accent, one emphasis.** Color is restrained. The accent marks the single most important action or state on each screen. If everything is highlighted, nothing is.

5. **Quiet confidence.** The interface doesn't explain itself. Labels are precise, actions are clear, and the curator is trusted to know the domain.

## Accessibility & Inclusion

- WCAG 2.1 AA minimum for all interactive elements
- Respect `prefers-reduced-motion`
- Verify accent color contrast against both light and dark surfaces (4.5:1 for text, 3:1 for UI components)
- CJK text must remain readable at body sizes; test with mixed Japanese-English content
